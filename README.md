# MERN Portfolio Projects

Five original, independently runnable portfolio demos: ShopFlow, BookEase, ClientDesk, SupportPilot and ServiceHub.

The `portfolio-live` branch contains the complete editable source under `mern-portfolio/` and the deployment blueprint. These applications use MongoDB, Express, React and Node.js. Sample accounts and records are fictional demonstration data.

Deployment status: hosting and database connections are required before public URLs can be verified. A GitHub source link is not a live application link.
